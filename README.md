# Cocina Capital — Backend

Backend de Cocina Capital, una app móvil Android que conecta a usuarios
con restaurantes de la Región de Valparaíso mediante tickets canjeables
por beneficios.

**Asignatura:** DSY1105 Desarrollo de Aplicaciones Móviles — Evaluación Parcial 4

- Oscar Torres

## Microservicios

| Microservicio | Puerto previsto | Función |
| --- | --- | --- |
| `usuarios-service` | `8081` | Registro, inicio de sesión y gestión del perfil. |
| `locales-service` | `8082` | Listar, consultar, crear, editar y eliminar locales. |
| `tickets-service` | `8083` | Gestionar compras de tickets, saldo y canje de cupones. |

## Tecnologías previstas

- Java 17
- Spring Boot
- MySQL
